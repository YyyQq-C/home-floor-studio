# HA 平面图卡片（开发预览）

本卡片仍处于开发预览阶段，支持 2D、可旋转 3D 展示、打开实体详情及按标记配置开关操作。设备标记可以设置离地高度；未设置时显示在墙体上方。完整安装流程已在隔离 HA 验证；家庭 HA 和真实设备仍未验证。

本机隔离的 Home Assistant Core 2024.12.5 测试中，使用 YAML 配置成功加载卡片和户型，验证了 2D/3D 切换。在存储模式仪表盘中，已通过 HA 卡片编辑窗口将标记绑定到测试用 `input_boolean`，保存并刷新后成功切换其状态。另在全新隔离实例中从初始化开始完成资源注册、仪表盘添加、绑定和 3D 显示。测试没有连接家庭 HA 或真实设备。

另已从生成器实际导出示例户型安装包，将其中的卡片和户型文件复制到隔离 HA，在 HA 的“添加卡片”界面找到并新建 Home Floor Studio 卡片，绑定模拟开关；刷新后确认开关状态变化。安装包中的卡片也已验证 3D 画布加载。随后在隔离 HA 的资源管理界面重新注册 JavaScript 模块，并确认仪表盘能加载卡片及实体状态。上述步骤经过分阶段验证，不代表家庭环境及真实设备已验证。

## 导出安装包

在生成器中点击“导出 HA 安装包”，得到包含当前户型、配套卡片、许可证和使用说明的 ZIP。解压后将其中的 `www/home-floor-studio/` 复制到 HA 配置目录的 `www/`，再按包内说明注册资源和配置卡片。覆盖同名文件前请先备份自己的内容。此方式仍需用户自行复制文件和添加仪表盘资源，不会自动修改 HA。

安装包中的卡片与生成器构建时的卡片一致，不含上传的参考底图或 AI 密钥。户型和标记名称仍可能包含家庭信息，请妥善保管。家庭环境的部署和设备验证尚未完成。

## 构建与放置

在已安装 Node.js 和依赖的开发电脑，在项目目录执行 `npm run build:ha`，生成 `dist-ha/home-floor-studio-card.js`。该命令只构建本地文件，不连接 HA。

在生成器中添加设备标记后，点击“导出 HA 户型”，得到 `home-floor-ha.json`。此文件不包含参考底图或 HA 令牌；设备位置和名称仍属于家庭信息，请按自己的隐私要求保管。

将两个文件复制到 HA 配置目录的 `www/home-floor-studio/`，在仪表盘资源中以 JavaScript 模块注册 `/local/home-floor-studio/home-floor-studio-card.js`。具体上传方式取决于用户的 HA 环境，本项目不会自动覆盖线上文件。

## 卡片配置

资源注册后，在 HA 仪表盘中添加 Home Floor Studio 卡片，填写户型文件路径，并在可视化编辑器中为每个标记选择实体。保存后可以切换 2D/3D；在 3D 视图中可使用“复位 3D 视角”重新显示完整户型。配置编辑器已在隔离 HA 中验证测试实体的绑定和保存，其他环境仍需验证。

也可以手动使用 YAML，将下面配置中的 `marker-id` 替换为导出 JSON 中 `project.markers` 内对应项目的 `id`，实体替换为自己 HA 中的实体：

```yaml
type: custom:home-floor-studio-card
project_url: /local/home-floor-studio/home-floor-ha.json
title: 我的家
view: 2d  # 可选 2d 或 3d，显示后可切换
entities:
  marker-id: light.living_room
# 可选：明确启用点击切换，默认是打开详情
actions:
  marker-id: toggle
```

户型加载失败时，检查路径和文件后可在卡片上点击“重新加载户型”。

卡片及配置编辑器读取的户型 JSON 上限为 20 MiB，按实际响应字节数检查；超限时停止读取并显示加载失败提示。请缩减户型后重新导出，不要把含底图的项目备份作为 HA 户型文件。

卡片读取实体当前状态；没有绑定、实体不存在、`unknown` 或 `unavailable` 时显示相应提示。每个标记默认点击打开实体详情；用户可以在卡片配置中明确选择“切换开关”，适用于状态为 `on` 或 `off` 的 `light`、`switch`、`fan` 和 `input_boolean` 实体。选择后点击会调用对应域的 `toggle` 服务，操作受 HA 账号权限及实体支持情况约束；失败时会提示。实体状态以 HA 返回为准。`input_boolean` 的详情打开和切换已在隔离 HA 中验证；其他实体类型及真实设备尚未在家庭 HA 中验证。

重新导出并替换户型文件后应刷新页面；在卡片配置界面点击“重新加载户型”可以重新读取同一路径的标记。保留原项目标记 ID 时，卡片配置中原有实体绑定和点击操作保持不变；删除或重新创建的标记会获得新 ID，需要重新绑定。更换文件前请备份用户配置及既有资源。卡片资源本身更新后，如果浏览器仍显示旧版本，可尝试强制刷新。

隔离 HA 中已验证一次更新：在生成器更改示例标记的名称和位置并保留 ID，重新导出并替换户型数据后，原测试实体绑定及切换操作仍然生效。此测试没有验证家庭 HA 的升级或真实设备。

在全新的隔离 Home Assistant Core 2024.12.5 配置中，已从首次设置完成初始化，再通过 HA 的资源管理页面注册卡片模块；随后在默认仪表盘的“创建部件”流程中新建卡片、绑定测试用 `input_boolean` 并保存。刷新后开关由 `off` 切换为 `on`，3D 画布成功显示。户型文件在初始化前由生成器导出并放入该隔离实例的 `www` 目录；这项验证没有接入真实设备或家庭 HA。
