# 使用指南（开发预览）

Home Floor Studio 是独立的户型编辑工具。可以手工绘制，也可以由用户自行配置兼容的 AI 服务辅助识别。当前输出为示意结果，不能作为施工图；真实 AI 服务及家庭 Home Assistant 安装尚未验证。

## 1. 准备项目与图纸

首次打开为空白户型，点击“加载示例”可以体验；加载示例会替换当前内容。要处理自己的图纸，可先“新建空白”，再点击“上传户型图”，选择不超过 5 MB、2400 万像素的 PNG 或 JPG。图纸只作为参考底图，编辑器不会自动把它变成墙体。

描图时可在左侧调整底图不透明度，并选择“透过房间查看底图”；这些设置只影响当前编辑画面，不改变导出成图。

如需调整，可在左侧使用“旋转和裁剪底图”或“四点透视校正”。透视校正需要依次选择四个角点；底图位置改变后，现有结构不会跟着移动，比例也需重新校准。应用调整前请核对现有内容并按提示确认。

## 2. 建立墙体

**手工方式**：选择“墙体”，按顺序点击每面墙的起点和终点，虚线会预览终点；可开启“正交绘制”限制为水平或垂直方向。开启“墙体及端点吸附”后，可连接已有墙端或墙身；选择工具下点击墙体，可拖动端点或在右侧编辑坐标、厚度和高度。拖动时可选择保持墙体连接，也可选择同步完全重合的房间顶点。

**AI 辅助方式**：展开“AI 辅助识别”，填写自己选择的兼容视觉聊天接口、模型名称和所需密钥，点击“发送图片并识别”。图片会发送给该服务。识别结果只作为候选预览；核对后可追加、替换或丢弃。服务的兼容性、跨域配置和费用由所选服务决定，当前仅验证过模拟接口。详见 [AI 辅助识别](ai-recognition.md)。

无论使用哪种方式，都需要检查墙体、门窗和房间，修正遗漏、错位及未连接的墙端。

## 3. 校准比例与创建房间

选择一面具有已知实际长度的墙，在右侧“已知墙长 (cm)”输入厘米数并点击“校准比例”。校准会影响整张图的画布比例；仅凭一条墙不能验证图纸是否变形，请继续核对其他尺寸。

选择“房间”，沿边界按顺序点击至少三个顶点，再点击“完成房间”；也可以在墙体闭合后点击“从墙体生成房间”。自动生成按墙体中心线计算，可能不等于墙的内侧；替换已有房间前会要求确认。之后选择房间可编辑名称、顶点、颜色和地面材质。没有房间时 3D 不生成地面。

## 4. 添加门窗、家具与设备

选择墙体后在右侧添加门或窗，再选择门窗调整位置、宽度及高度。门可以设置闭合或 90° 开启方向。选择“家具”类型后点击画布放置，右侧可调整尺寸和旋转。

选择“设备”后点击画布添加标记，切回“选择”后可以调整名称、类型、内置图标、所属房间、二维位置和 3D 离地高度。高度留空时在 HA 3D 展示中自动放在墙体上方。标记的 HA 实体在安装卡片后绑定；编辑器不会直接操作真实设备。

## 5. 检查与导出

在左侧点击“检查户型”，按提示检查未连接墙端、墙体中心线重叠、比例及门窗裁剪等问题；悬空墙可以有意保留。检查只覆盖部分常见情况；超过 500 面墙或 500 个门窗时仅检查各自前 500 项；问题超过 200 条时只显示前 200 条。界面会提示未覆盖的范围。切换“3D 预览”检查模型，再按用途导出：

| 按钮 | 用途 |
| --- | --- |
| 导出项目 | 保存可再次导入编辑器的 JSON 备份，包含参考底图；导入文件最大为 20 MB；导出超过此限制时仍会保留备份文件，并提示需要缩减项目后重新备份。 |
| 导出 2D / 导出 PNG | 生成 SVG / PNG 成图，不含参考底图；可在左侧选择 PNG 最长边（1600、2400 或 3200 像素）、是否采用紧凑成图范围、是否包含设备标记、是否使用透明背景；紧凑范围围绕内容留白，透明只作用于户型外部。 |
| 导出 GLB | 导出简化三维模型，几何尺寸在文件中使用米。 |
| 导出 HA 户型 | 导出供配套 HA 卡片读取的数据，不含参考底图或 AI 密钥。 |
| 导出 HA 安装包 | 打包户型数据、卡片、许可和安装说明；需要用户自行放置文件并配置仪表盘。 |
| 导出完整项目包 | 在右侧“项目”面板导出 ZIP，包含可编辑项目 JSON、按当前设置生成的 SVG / PNG、GLB、HA 安装包和导入说明。解压后可将 JSON 导回编辑器；项目 JSON 可能包含原始参考图。 |

项目自动保存在当前浏览器，但清理浏览器数据会丢失；换电脑或网址前应导出项目备份。HA 安装及实体绑定步骤见 [HA 平面图卡片](ha-preview.md)，其中记录了隔离 HA 的分阶段验证范围；家庭环境仍需验证。

## 本地项目无法读取时

如果打开时提示无法读取本地项目，可先点击“导出原始记录”保存原样快照，再使用此前“导出项目”生成的 JSON 备份恢复。原始记录快照用于排查，并非普通项目备份格式。确认恢复后，旧记录也会保留在当前浏览器存储中；清理浏览器数据会同时删除该副本，因此仍应妥善保存下载文件。若其他页面已修复当前记录，恢复会拒绝覆盖，请重新加载。存储权限被禁用或浏览器无法打开数据库时，导出和恢复也可能失败，需要先解决存储访问问题。

3D 预览显示设备图标和名称，可核对设备位置及离地高度；标记不会写入 GLB 网格。3D 预览支持旋转和缩放；选择“复位 3D 视角”可重新显示完整户型。

家具工具包含床、沙发、餐桌、椅子、柜子、电视柜、厨房地柜及基础卫浴；家具为简化造型，可调整尺寸、旋转和颜色。

删除房间或替换识别结果后，使用“检查户型”查找设备失效的房间关联，并点击“查看对象”重新选择。导入项目时会拒绝空白或重复的对象 ID，以免发生选择和 HA 绑定冲突。

选中墙体后可调整墙面颜色和 3D 表面光泽（哑光、柔光或亮光）；这些光泽为简化材质，不带墙面纹理。

保存中、保存失败或发生多标签页冲突时，离开页面会请求浏览器提示；请等待保存完成或先导出项目备份。浏览器可能不在所有关闭场景中显示提示。

新手操作指引中可下载横向、纵向和异形三张合成示例图，用于练习上传和描图；它们不是实际户型或施工图。

手工描图遇到门窗缺口时，可先沿墙体中心线画完整墙，再选中墙体添加门或窗；这样房间生成可以依据闭合墙线计算，门窗仍会在 2D 和 3D 中留出开口。
