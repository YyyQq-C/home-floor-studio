# 数据与隐私说明

本说明对应当前开发预览版本，依据生成器及配套 HA 卡片的实现整理。自行部署者增加的统计、代理、登录或服务器日志应由部署者另行说明。

## 编辑与保存

上传的 PNG/JPG 在浏览器中读取，用作参考底图；手工编辑、图片旋转裁剪、透视校正和模型生成在浏览器执行。当前实现没有内置遥测或项目云同步。

当前项目优先存入该网址下的 IndexedDB；浏览器没有 IndexedDB 接口时使用 localStorage。数据可能包含图纸、房间名称和设备位置。旧版记录及损坏记录的恢复副本可能继续保存在浏览器中；“新建空白”不会保证清除这些副本。

清除该站点的浏览器存储可移除本地项目及副本，但也会造成不可恢复的数据丢失。下载文件、系统备份及其他设备上的副本需要分别管理。更换网址或浏览器前请先导出需要保留的项目。

## AI 辅助识别

只有用户点击“发送图片并识别”后，当前参考底图才会随识别提示和模型名称发送到填写的服务地址。若填写密钥，请求还会包含对应的 Authorization 头。服务地址和模型由用户选择；当前未内置服务商或验证真实服务。

API 密钥只保留在页面内存，不写入项目或浏览器项目存储；刷新或关闭页面会清除。请求从浏览器直接发送，不经过本项目提供的代理。第三方服务可能保存图片和请求，并产生费用，应根据所选服务的政策判断；取消浏览器请求不能保证对方停止处理或删除已收到的数据。

当前只接受 HTTPS 服务，以及本机 localhost、127.0.0.1、::1 的 HTTP 服务。具体兼容条件见 [AI 辅助识别](ai-recognition.md)。

## 导出与 HA

| 导出内容 | 数据范围 |
| --- | --- |
| 项目备份 JSON | 包含参考底图及可编辑户型；可能含家庭信息。 |
| 完整项目 ZIP | 包含项目备份、2D/3D 成品及 HA 安装包；项目备份可能包含原始户型图。 |
| SVG、PNG、GLB | 不含参考底图，但图形、房间名称或布局仍可能暴露家庭信息；设备标记是否显示取决于格式和导出设置。 |
| HA 户型 JSON / 安装包 | 不含参考底图和 AI 密钥；包含户型、设备名称、位置和标记 ID。 |

HA 实体绑定及点击操作存放在 HA 卡片配置中。卡片通过同源 `/local/` 路径读取户型，使用 HA 提供的状态及服务接口；明确选择切换操作后，会调用绑定实体的服务。卡片不要求用户在户型文件中填写 HA 令牌。

导出文件没有加密。上传到 HA 静态目录前，应按自己的家庭信息保护要求决定可访问范围，不要将“无参考底图”理解为匿名或公开安全。分享前请检查名称、设备位置及布局。

站点首次加载、读取示例图和打包 HA 安装包需要访问部署站点的静态资源；部署服务器可能记录访问日志。纯静态分发包不包含项目接收后台。实际部署环境的访问控制和日志保留由部署者负责。
