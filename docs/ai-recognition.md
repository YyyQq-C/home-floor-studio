# AI 辅助识别（开发预览）

在编辑器上传 PNG 或 JPG 户型图，展开“AI 辅助识别”，由用户填写视觉服务的完整请求地址、模型名称和需要的 API 密钥，再点击发送。系统不会预先选择服务或自动上传图片；发送后服务方可能处理、保存图片并产生费用，具体以用户选择的服务为准。

当前适配的接口使用常见的视觉聊天请求格式：POST JSON，`messages` 包含文本和 `image_url`，响应读取 `choices[0].message.content`。服务还必须允许浏览器跨域访问。不同供应商接口可能不兼容，需自行确认；本功能目前只经过模拟服务测试，未验证任何实际服务。

出于密钥传输考虑，远程地址仅允许 HTTPS，本机 `localhost`、`127.0.0.1` 和 `::1` 允许 HTTP。密钥仅存于当前页面内存，不写入项目、浏览器本地存储或导出文件。使用浏览器直接请求意味着服务方和网络环境会收到请求及图片；请只使用可信服务。关闭或刷新页面会清除密钥。

识别目前生成墙体、房间及门窗候选。无效的墙体、房间以及无法绑定到有效候选墙体的门窗会被跳过并分别提示数量，其他有效候选仍可使用；门窗高度使用示意默认值。家具与所有尺寸仍需手动确认。结果不是实测图纸。候选会以绿色虚线、半透明区域及门窗标记叠加在 2D 底图上，供用户检查，也可以丢弃；候选不会自动应用；“追加候选”保留原结构，“替换墙体和房间”会删除原墙体、依附的门窗和房间，保留家具、设备和底图，但设备的原房间关联可能失效。替换现有结构前需要确认，取消时保留候选；替换后刷新页面前可撤销。操作前请导出项目备份。模型可能遗漏、误认或返回无法解析的结果，应逐项校对。

识别失败时会区分认证、额度或限流、服务 HTTP 错误、网络或跨域、响应格式、空结果、取消和超时；服务返回正文不会显示在错误提示中。
